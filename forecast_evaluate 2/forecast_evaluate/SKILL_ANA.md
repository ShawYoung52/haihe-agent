### 输入数据说明

数据包含三个维度：`time_session`（预报时效）、`area`（区域）、`daily`（日期）。可能涉及以下两类要素的指标：

**温度要素**

- 平均绝对误差（MAE）：越小越好
- 平均误差（ME）：正值表示预报偏高，负值表示偏低
- 2°C准确率（%）：越高越好

**降水要素**

- 偏差（Bias）：>1 表示空报多，<1 表示漏报多，越接近1越好
- 准确率（%）：越高越好
- TS评分（0~1）：越高越好

### 较差定义标准

以下标准用于判定**天津预报**在某一区域/时效/日期的表现是否“相对较弱”（即需要重点关注的对象）。**注意**：标准依据分析维度（`area` / `daily` / `time_session`）略有不同。

#### 通用标准（适用于 `area` 和 `daily` 维度）

- **温度准确率**： ≤ **80%**
- **温度MAE**： ≥ **1.5°C**
- **温度ME**：绝对值 ≥ **1.0°C**
- **降水准确率**： ≤ **85%**
- **降水TS评分**： ≤ **整体均值**
- **降水偏差**： ≤ **0.6** 或 ≥ **1.4**

#### 时效维度标准（适用于 `time_session` 维度）

**对于预报时效 ≤ 72 小时（含72小时）：** 
采用与上述通用标准相同的阈值（即温度准确率≤80%，MAE≥1.5°C，|ME|≥1.0°C；降水准确率≤85%，TS≤整体均值，偏差≤0.6或≥1.4）。

**对于预报时效 > 72 小时：**  
采用以下更宽松的阈值：

- **温度准确率**： ≤ **70%**
- **温度MAE**： ≥ **3°C**
- **温度ME**：绝对值 ≥ **1.5°C**
- **降水准确率**： ≤ **70%**
- **降水TS评分**： ≤ **整体均值**
- **降水偏差**： ≤ **0.3** 或 ≥ **2.0**

> **特别说明（降水TS评分整体均值的计算方式）**：
> - 对于 `area` 和 `daily` 维度，“整体均值”指 **天津预报自身在所有区域（或所有日期）上的TS评分平均值**。
> - 对于 `time_session` 维度，“整体均值”指 **同一预报时效下，所有对比预报（如国家指导、天津预报、ECMWF）的TS评分平均值**，而不是同一预报在不同时效上的平均值。例如，判断时效96小时的TS评分是否“高于整体均值”时，应计算该96小时下各家预报的TS评分均值作为比较基准。

### 分析要求

#### 1. 总体结论（1~2句话）

- 评价**天津预报**在主要指标上的整体表现（优于/接近/弱于其他预报）。
- 指出**天津预报**最突出的问题（如某一指标偏弱、某区域/时效明显不足），不使用“极差”等极端词汇。

#### 2. 分段分析（每项指标控制在3行以内，引用关键数据）

**排序要求**：列出符合条件的区域、时效或日期时，须按指标值从差到好排序，具体为：准确率升序、MAE降序、ME绝对值降序、降水准确率升序、TS评分升序、偏差偏离1的程度降序。

- **温度**：按 准确率 → MAE → ME 的顺序进行分析。
  - 要求：先给出**天津预报**的整体值，然后根据“较差定义标准”分别列出符合条件的区域、时效或日期。**表格形式**：每个子项（准确率/MAE/ME）单独使用一个**横向表格**，表头第一列为维度名称（如“区域”、“日期”、“时效”），后续列依次为各较差样本的名称，第二行为对应的指标数值。若无较差样本则写“无”。
  
- **降水**：按 准确率 → TS评分 → 偏差 的顺序进行分析。
  - 要求：先给出**天津预报**的整体值，然后根据“较差定义标准”分别列出符合条件的区域、时效或日期。**表格形式**同温度：每个子项使用一个横向表格。若无则写“无”。

#### 3. 重点定位（聚焦天津预报较差样本，其他预报仅作为参照）

根据给定维度选择侧重点：

- **若维度为 `area`**：
  - 先给出**天津预报**在所有区域的平均值（准确率/TS/MAE等）。
  - 再根据“较差定义标准”，列出**天津预报**表现相对较弱的区域（可按严重程度排序）。
  - 对每个较差区域，简要对比**国家指导**、**ECMWF**等其他预报的同项数值。

- **若维度为 `time_session`**：
  - 先给出**天津预报**在所有时效的平均表现（准确率/TS/MAE等）。
  - 再根据“较差定义标准”，列出**天津预报**表现相对较弱的时效（可按严重程度排序）。
  - 对每个较差时效，简要对比**国家指导**、**ECMWF**等其他预报在同时效下的同项数值。

- **若维度为 `daily`**：
  - 先给出**天津预报**在所有日期的平均表现（准确率/TS/MAE等）。
  - 再列出**天津预报**表现相对较差的日期（按准确率或TS评分排序，若数据充分可同时列出MAE最大的日期）。判定“最差”时仍需根据“较差定义标准”进行筛选。
  - 对每个较差日期，简要对比**国家指导**、**ECMWF**等其他预报在同日期的同项数值。

### 输出风格约束

- 不使用“极差”“非常差”“灾难性”“极低”“巨大”等极端词汇，改用“相对较弱”“有提升空间”“偏低”等中性表达。
- 关键数据必须直接引用（如“准确率=84.09%”）。
- 若**天津预报**在所有区域/时效/日期均表现良好，可简要总结并跳过“较差样本”的详细列出。
- 输出时，将预报产品名称（如“**天津预报**”、“**国家指导**”、“**ECMWF**”等）加粗。
- 日期格式：在提到具体日期（daily维度）时，统一使用“X月X日”格式（如“5月1日”），不写“05月01日”或“2026-05-01”。年份仅在总体结论开头的时段描述中保留（如“2026年5月1日至5月8日”）。
