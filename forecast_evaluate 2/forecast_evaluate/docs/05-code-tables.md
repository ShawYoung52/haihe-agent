## 算法说明

### 降水算法

| 术语 | 说明 |
|------|------|
| PC | 准确率，晴雨预报正确率 |
| TS | 技巧评分，降水预报技巧 |
| BIAS | 偏差，预报频次与实况之比 |

### 温度算法

| 术语 | 说明 |
|------|------|
| PC:2 | 2℃准确率，误差±2℃以内比例 |
| PC:1 | 1℃准确率，误差±1℃以内比例 |
| ME | 平均误差，系统偏差 |
| MAE | 平均绝对误差 |
