# 预报检验 API 参考

## 接口信息

- **接口地址**: `http://10.226.107.74:31002/exam/common/api`
- **方法**: POST
- **功能**: 预报检验查询

## 请求格式

```json
{
    "u": "H8w76Mt7PGNjVh",
    "p": "a9u5DsEDvRH3H2mk7NaMUHkrbvmqjiqh",
    "params": {
        "topic": "exam_service",
        "jsonData": "<Base64编码的JSON数据>",
        "timeOut": 0
    }
}
```
